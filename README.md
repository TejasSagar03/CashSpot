CashSpot is a tactical, geolocation-based utility web application. Designed with a brutalist, minimalist aesthetic inspired by Nothing OS, it empowers operators to seamlessly pinpoint nearby ATMs, locate financial services, and manage node data within their immediate physical perimeter.

---

## ⚙️ SYSTEM_SPECS

*   **Tactical Onboarding:** A buttery-smooth, hardware-style initialization sequence utilizing Framer Motion for gesture-based, snap-scrolling transitions.
*   **Geolocation Radar:** Integrated OpenStreetMap (OSM) radar with both Standard Vector and Satellite rendering engines to physically track down financial service points.
*   **Hardware Interface UI:** Pixel-perfect Dark/Light mode integration with a subtle, surgical watermark grid and brutalist `#ff0031` (Nothing Red) accents.
*   **System Telemetry:** A dynamic control center modal managing user preferences, including haptic feedback triggers, map engines, and customizable terminal phosphor themes.

---

## 🛠️ TECH_STACK

**Frontend (Interface)**
*   React.js
*   Tailwind CSS (Brutalist/Hardware-style implementation)
*   Framer Motion (High-fidelity spring & gesture animations)

**Backend & Data (Core)**
*   Node.js & Express (Backend API Architecture)
*   MongoDB (Primary Data Persistence & Spatial Queries)
*   Firebase Authentication (Secure Operator Login/Signup)

**Deployment**
*   Vercel
